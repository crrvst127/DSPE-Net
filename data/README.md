# 数据目录

三个目录使用相同的已配准二维网格。每个样本保存为一个单通道 `.npy` 数组，轴序为 `[y, x]`，宽和高均可被 4 整除。文件名可自定，程序按文件名自然排序，请确保该顺序与采集顺序一致。多个序列应分别运行。

| 目录 | 放入的内容 |
|---|---|
| `development/` | 一段连续开发序列，至少 10 个不同样本，供五折训练和验证。 |
| `evaluation/` | 独立留出的序列，至少 2 个样本。第一个样本作为预测起点，其后的样本不会输入预测器。开发集与评估集的样本内容须分离。 |
| `history/` | 同场景的历史序列，至少 5 个样本。最近 5 个用于辨识，均应在预测起点或之前采集，排除所有未来目标。 |

等间隔数据默认最后一个历史样本比起点早一步。数模每步 10 分钟，卫星名义每步 1 分钟。若时间不规则，或历史序列包含起点样本，请在 `history/times.txt` 中为所有历史样本逐行填写实际采集时刻（分钟，相对于起点，按文件排序严格递增，末值 ≤ 0）。不等间隔预测用 `--intervals` 依次指定目标间隔，个数等于 `--steps`。

默认辨识外块边长为 128 像素，小网格可通过 `--tile-size` 调整。所有样本使用相同的幅值单位；若训练输入需要归一化，可设置 `--scale` 为对应除数。
