# DSPE-Net

| 数据目录 | 样本 |
|---|---|
| `data/development/` | 训练与验证，≥ 10 个不同样本 |
| `data/evaluation/` | 独立评估，≥ 2 个，首个为预测起点 |
| `data/history/` | 历史观测，≥ 5 个，时间不晚于预测起点 |

[输入格式](data/README.md) · 代码来源：[ConvLSTM-PyTorch](https://github.com/jhhuang96/ConvLSTM-PyTorch)、[PySINDy](https://github.com/dynamicslab/pysindy)
